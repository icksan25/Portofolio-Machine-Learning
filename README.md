# 🤖 Proyek Analisis Machine Learning

## 📌 Tentang Proyek
Ini adalah proyek analisis data yang saya kerjakan menggunakan Python dan Google Colab.
Tujuannya adalah untuk memprediksi popilaritas lagu di spotify.

## 🛠️ Teknologi yang Digunakan
- Python
- Pandas & NumPy (Analisis Data)
- Matplotlib & Seaborn (Visualisasi)
- Scikit-Learn (Modeling Machine Learning)

## 📊 Hasil Analisis
Model ini berhasil mencapai akurasi sebesar 76%.
